# Harness Platform × Token Factory

中文 AI 软件栈架构互动学习网站，版本 1.6.0。

- [在线访问](https://coingcy.github.io/harness-token-factory/)
- [完整源码与部署资料下载](harness-token-factory-v1.6.0-source.zip)

网页支持完整架构展示、悬停关联高亮、点击查看详细说明，以及 Agent 与推理模拟。

`index.html` 为可直接部署的自包含版本，源代码、测试、说明、参考图和自动发布配置保存在源码 ZIP 中。解压后进入项目目录，使用 Node.js 20.11+ 执行 `npm test`、`npm run preview`。

GitHub Pages 使用 main 分支根目录发布。修改 index.html 并提交即可更新网站。
